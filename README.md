# NEXTGUARD ICT website

Static website for GitHub Pages.

## Publish
1. Create a public repository named `nextguardict.github.io`.
2. Upload `index.html`, `CNAME`, and this README to the repository root.
3. In Settings → Pages, select **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. For the custom domain, use `nextguardict.com` and enable HTTPS once DNS is verified.

The contact form uses `mailto:` and opens the visitor's email application; it does not store submissions.
